# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS and JavaScript. It allows users to create, search and delete notes while organizing them into Personal, Work and Study categories. Notes are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes
- Choose a note category
- Personal, Work and Study categories
- Search notes
- Delete notes
- Validate empty notes
- Limit notes to 200 characters
- Display note count
- Display note creation date and time
- Save notes using localStorage
- Responsive design for smaller screens
